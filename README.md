## Лабораторная работа №1 — Множества и битовые поля

### Описание
Разработка программной реализации математических множеств с использованием битового представления. Работа включает создание классов для хранения и обработки множеств, а также графического приложения на Qt для взаимодействия с пользователем.

### Структура проекта

| № | Файл | Описание |
|:---:|:---|:---|
| 1.1 | `TBitField.h` | Класс битового поля. Обеспечивает хранение элементов в виде массива битов, добавление элементов, копирование и выполнение операций объединения, пересечения и дополнения. |
| 1.2 | `TSet.h` | Класс математического множества на основе `TBitField`. Реализует задание универсума, создание множества из строки и основные операции над множествами. |
| 1.3 | `widget.h` | Объявление класса главного окна `Form`. Содержит обработчики пользовательского ввода, нажатий кнопок и вспомогательные методы для работы с множествами. |
| 1.4 | `widget.ui` | Описание графического интерфейса, созданного в Qt Designer. Содержит поля ввода универсума и множеств A и B, кнопки операций и область вывода результата. |
| 1.5 | `widget.cpp` | Реализация логики главного окна. Отвечает за обработку введённых данных, создание множеств, выполнение операций и отображение результатов. |
| 1.6 | `main.cpp` | Точка входа в приложение. Выполняет инициализацию Qt, создание главного окна и запуск программы. |

### Основные возможности
- Представление множеств с помощью битовых полей.
- Задание размера универсума.
- Создание множеств на основе пользовательского ввода.
- Проверка допустимости элементов относительно универсума.
- Выполнение операций объединения, пересечения и дополнения.
- Отображение результатов в графическом интерфейсе Qt.

## Лабораторная работа №2 — Векторы и матрицы

### Описание
Разработка шаблонного класса динамического вектора и класса верхнетреугольной матрицы на его основе. Работа направлена на изучение шаблонного программирования, управления динамической памятью, копирования объектов и перегрузки операторов для реализации математических операций.

### Структура проекта

| № | Файл | Описание |
|:---:|:---|:---|
| 2.1 | `MyVector.h` | Шаблонный класс динамического вектора. Обеспечивает хранение элементов произвольного типа, управление динамической памятью, копирование, присваивание и доступ по логическим индексам. Реализует арифметические операции над векторами. |
| 2.2 | `TMatrix.h` | Класс верхнетреугольной матрицы на основе `MyVector`. Обеспечивает хранение матрицы заданного размера, доступ к её элементам, копирование и присваивание, а также выполнение основных матричных операций. |

### Основные возможности
- Работа с векторами произвольных типов данных.
- Управление динамической памятью.
- Копирование и присваивание объектов.
- Доступ к элементам по логическим индексам.
- Сложение и вычитание векторов и матриц.
- Умножение на скаляр.
- Вычисление скалярного произведения векторов.
- Умножение верхнетреугольных матриц.
