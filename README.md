## Лабораторная работа №1

**Цель:** реализация математических множеств на основе битового представления с графическим интерфейсом Qt.

**Файлы проекта:**

| Файл | Назначение |
|---|---|
| `TBitField.h` | Хранение и обработка битовых полей. |
| `TSet.h` | Реализация математических множеств. |
| `widget.h` | Объявление главного окна и обработчиков событий. |
| `widget.ui` | Описание графического интерфейса Qt. |
| `widget.cpp` | Обработка ввода, операции над множествами и вывод результатов. |
| `main.cpp` | Инициализация и запуск приложения. |

**Реализовано:**
- Создание множеств и задание универсума.
- Проверка допустимости элементов.
- Объединение, пересечение и дополнение множеств.
- Взаимодействие с пользователем через Qt.

## Лабораторная работа №2

**Цель:** реализация операций с треугольными матрицами с графическим интерфейсом Qt.

**Файлы проекта:**

| Файл | Назначение |
|---|---|
| `MyVector.h` | Шаблонный динамический вектор с управлением памятью и арифметическими операциями. |
| `TMatrix.h` | Верхнетреугольная матрица на основе `MyVector`. |

**Реализовано:**
- Работа с элементами произвольных типов.
- Управление динамической памятью, копирование и присваивание.
- Доступ по логическим индексам.
- Сложение и вычитание векторов и матриц.
- Умножение на скаляр и скалярное произведение.
- Умножение верхнетреугольных матриц.
