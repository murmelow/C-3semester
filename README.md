## Лабораторная работа №1

**Цель:** реализация математических множеств на основе битового представления с графическим интерфейсом Qt.

**Файлы проекта:**

| Файл | Назначение |
|---|---|
| `TBitField.h` | Хранение и обработка битовых полей. |
| `TSet.h` | Реализация математических множеств. |
| `widget.h` | Объявление главного окна и обработчиков событий. |
| `widget.ui` | Описание графического интерфейса Qt. |
| `widget.cpp` | Обработка ввода, операции над множествами и вывод результатов. |
| `main.cpp` | Инициализация и запуск приложения. |

**Реализовано:**
- Создание множеств и задание универсума.
- Проверка допустимости элементов.
- Объединение, пересечение и дополнение множеств.
- Взаимодействие с пользователем через Qt.

## Лабораторная работа №2

**Цель:** реализация операций с верхнетреугольными матрицами на основе шаблонного динамического вектора с графическим интерфейсом Qt.

**Файлы проекта:**

| Файл | Назначение |
|---|---|
| `MyVector.h` | Шаблонный динамический вектор с управлением памятью, доступом к элементам и арифметическими операциями. |
| `TMatrix.h` | Реализация верхнетреугольных матриц на основе `MyVector`, включая доступ по индексам и операции над матрицами. |
| `mainwindow.h` | Объявление главного окна, методов работы с матрицами и обработчиков операций. |
| `mainwindow.ui` | Описание графического интерфейса Qt: таблицы матриц, выбор операций и ввод скалярного коэффициента. |
| `mainwindow.cpp` | Инициализация интерфейса, обработка ввода, выполнение операций над матрицами и вывод результатов. |
| `main.cpp` | Инициализация и запуск приложения Qt. |

**Реализовано:**

- Создание и отображение верхнетреугольных матриц.
- Изменение размера матриц (от 1 до 10).
- Ввод и проверка целочисленных элементов.
- Исключение доступа к элементам ниже главной диагонали.
- Сложение и вычитание матриц.
- Умножение верхнетреугольных матриц.
- Умножение матриц на скалярный коэффициент.
- Вывод результатов операций через графический интерфейс Qt.
- Обработка ошибок ввода и вычислений.
