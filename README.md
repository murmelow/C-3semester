lab_1.1 (TBitField.h) — класс для хранения множества в виде битового поля. Он управляет массивом битов, позволяет добавлять элементы, копировать поле, преобразовывать его в строку и выполнять операции объединения, пересечения и дополнения.

lab_1.2 (TSet.h) — класс, реализующий математическое множество на основе TBitField. Он задаёт универсум U, позволяет добавлять элементы, создавать множество из строки и выполнять основные операции над множествами: объединение, пересечение и дополнение.
