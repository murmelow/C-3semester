lab_1.1 (TBitField.h) — класс для хранения множества в виде битового поля. Он управляет массивом битов, позволяет добавлять элементы, копировать поле, преобразовывать его в строку и выполнять операции объединения, пересечения и дополнения.

lab_1.2 (TSet.h) — класс, реализующий математическое множество на основе TBitField. Он задаёт универсум U, позволяет добавлять элементы, создавать множество из строки и выполнять основные операции над множествами: объединение, пересечение и дополнение.
lab_1.3 (widget.h) — заголовочный файл класса окна Form. Он описывает окно приложения: какие в нём есть слоты (обработчики ввода в поля N, A и B и нажатия кнопок объединения, пересечения и дополнения) и вспомогательные функции для чтения N и преобразования введённого текста в множество.

lab_1.4 (widget.ui) — файл с визуальным дизайном формы, собранный в Qt Designer. В нём описаны поля ввода размера универсума N, множеств A и B, кнопки операций ∨, ∧, ¬ и поле для вывода результата.

lab_1.5 (widget.cpp) — реализация класса Form. Здесь кнопки и поля связываются с обработчиками. Введённый текст превращается в множество TSet: числа вне диапазона от 1 до N отбрасываются, остальные сортируются по возрастанию. Затем выполняются операции над множествами, а результат выводится в окно.

lab_1.6 (main.cpp) — точка входа в программу. Создаёт приложение Qt, формирует окно Form и показывает его на экране.
